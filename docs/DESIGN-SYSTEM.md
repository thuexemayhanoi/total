# Hệ thống thiết kế TOTAL ATLAS

## Ý tưởng
Editorial + Knowledge Atlas + Technical Magazine + Knowledge Graph. Không giống SaaS landing, admin dashboard, spam SEO blog hay WordPress template phổ thông.

## Màu
- Nền: `#FBFAF6`; chữ: `#16243D`.
- Thương hiệu cobalt: `#3157D5` (đậm `#26449F`); nhấn amber: `#B45309`; phụ: `#64748B`; footer navy đậm; card trắng.
- Token màu canonical là `assets/css/atlas.css` (biến `--bg`, `--ink`, `--cobalt`, `--amber`, …); tài liệu này không thay thế atlas.css.
- Dùng màu tiết chế, không lạm gradient, không glassmorphism nặng.

Thuê Xe emerald, Guide cobalt, Hub navy, Wiki violet, Learn cyan, Moto blue, Ride teal, Tips amber, Docs slate, News red, Local emerald, Map cyan, Garage orange, Market gold, Review purple.

## Thành phần bài viết
Breadcrumb, nhãn chuyên mục, H1, tóm tắt, câu trả lời nhanh, điểm chính, mục lục, H2/H3, danh sách kiểm tra, các bước thực hiện, bảng so sánh, lưu ý, cảnh báo, nguồn tham khảo, bài liên quan — tên hiển thị bằng tiếng Việt.
